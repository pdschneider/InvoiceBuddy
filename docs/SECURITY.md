# Security Policy

Thank you for taking an interest in supporting the security of Invoice Buddy.

## Supported Versions

Only the most recent version of Invoice Buddy will have all of the latest security patches. Always keep your version up-to-date.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately so it can be addressed before public disclosure.

**Please do not report security vulnerabilities through public GitHub issues.**

Email: bugs@phillipplays.com

### What to include

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any proof-of-concept code or screenshots
- Your name or handle for acknowledgment (optional)

I'll do my best to respond promptly, though response times may vary depending on circumstances.
